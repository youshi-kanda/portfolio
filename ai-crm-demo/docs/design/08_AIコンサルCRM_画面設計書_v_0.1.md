# AIコンサルCRM 画面設計書 v0.2

## 1. 本書の目的

本書は、AIコンサルCRMにおける主要画面、画面構成、画面遷移、各画面の役割、表示項目、操作項目を定義するものである。

本サービスは、公式LINEを主要な顧客接点として活用する個人店・小規模店舗向けに、顧客データ・売上データ・地域ニーズを整理し、集客・再来店・顧客フォロー・発信施策をAIが提案する相談型マーケティングCRMである。

画面設計では、単なる顧客管理画面ではなく、以下の流れをユーザーが迷わず実行できることを重視する。

```text
自社状況を見る
↓
顧客状態・ニーズを見る
↓
AIに相談する
↓
今週やる施策を決める
↓
対象者と文案を確認する
↓
公式LINE/SNS/Google/個別対応で実行する
↓
結果を記録する
↓
次回改善案を見る
```

## 2. 画面設計の基本方針

### 2.1 UI方針

| 方針 | 内容 |
|---|---|
| 状況がすぐ分かる | 売上、顧客状態、施策、発信状況をダッシュボードで把握できる |
| 次にやることが分かる | AIが今週・今月の優先アクションを提示する |
| 複雑なタグを見せすぎない | 詳細分類は本サービス側で管理し、画面上は目的・対象・理由を中心に表示する |
| 手動運用でも迷わない | 公式LINEのみの店舗でも対象者リストと文案を見て実行できる |
| AI提案を鵜呑みにさせない | 根拠、信頼度、注意点、承認要否を明示する |
| 店舗と代理店の両方に対応する | 店舗直接利用と複数店舗支援の両方に耐える構成にする |
| 初期は外部APIに依存しない | CSV、手入力、スプレッドシート連携を中心に設計する |

### 2.2 情報設計の考え方

本サービスでは、画面上の中心情報を以下の4種類に分ける。

| 情報種別 | 内容 | 主な画面 |
|---|---|---|
| 状況情報 | 売上、顧客、発信、施策の現状 | ダッシュボード、自社診断 |
| 判断情報 | 顧客状態、推定ニーズ、優先度、根拠 | 顧客インサイト、セグメント整理 |
| 実行情報 | 対象者、配信文、投稿文、実行手順 | 施策管理、発信作成 |
| 改善情報 | 結果、反応、予約、売上、改善案 | 結果記録、レポート |

## 6. S02 初期セットアップ画面

### 6.1 目的

店舗が初回利用時に必要な情報を登録し、AI診断ができる状態にする。

### 6.2 ステップ構成

```text
Step 1：店舗基本情報
Step 2：業種・サブ業種選択
Step 3：メニュー・価格登録
Step 4：店舗の強み・課題登録
Step 5：利用中ツール登録
Step 6：顧客/予約/売上データ取込
Step 7：初期診断実行
```

### 6.3 入力項目

| 項目 | 内容 | 必須 |
|---|---|---|
| 店舗名 | 店舗名 | 必須 |
| 業種 | エステ、整体、パーソナルジム等 | 必須 |
| 店舗エリア | 市区町村、駅名、商圏 | 必須 |
| メニュー | メニュー名、価格、所要時間 | 必須 |
| 主力メニュー | 集客・収益の中心メニュー | 必須 |
| 店舗の強み | 差別化要素 | 必須 |
| 現在の課題 | 集客、再来店、客単価、休眠など | 必須 |
| 利用中ツール | 公式LINE、Lステップ、Instagram等 | 必須 |

### 6.4 出力

- 初期診断サマリ
- 今週の推奨アクション
- データ不足項目
- 公式LINEのみで足りるかの初期コメント

### 7.1 目的

### 7.2 画面構成

```text
┌────────────────────────────┐
│ 今月の状況サマリ             │
├──────────────┬─────────────┤
│ KPIカード群     │ AI診断カード   │
├──────────────┬─────────────┤
│ 今月の重点目的カード │ Why/根拠カード │
├──────────────┴─────────────┤
│ 今週の優先アクション          │
├──────────────┬─────────────┤
│ 顧客状態分布     │ 施策進捗       │
├──────────────┴─────────────┤
│ 注意・未対応タスク            │
└────────────────────────────┘
```

### 7.3 表示項目

| 領域 | 表示内容 |
|---|---|
| KPIカード | 売上、新規数、リピート数、客単価、休眠顧客数、施策実行率 |
| AI診断カード | 今月の主な課題、原因仮説、信頼度 |
| 今月の重点目的カード | 戦略目的、Why、根拠、信頼度、注意点、不足データ、推奨チャネル、推奨施策候補 |
| 今週の優先アクション | 優先度、施策名、対象、期限、ステータス |
| 顧客状態分布 | 新規、初回後、リピーター、休眠予備軍、休眠、VIP |
| 施策進捗 | 提案中、承認待ち、実行済み、結果入力待ち |

### 7.4 主な操作

| 操作 | 遷移先 |
|---|---|
| AIに相談 | S04 |
| アクションを確認 | S08 |
| 重点目的を確認 | S21（Phase1はカード詳細表示またはダッシュボード内表示） |
| 顧客状態を見る | S05 |
| 施策を作成 | S09/S10 |
| 結果を入力 | S12 |
| レポートを見る | S13 |

## 8. S04 AI相談画面

### 8.1 目的

店舗オーナー、店長、代理店・コンサルが、売上・集客・LINE運用・SNS発信・顧客フォローについてAIに相談する。

### 8.2 画面構成

```text
┌────────────────────────────┐
│ 相談カテゴリ / 店舗 / 期間選択 │
├────────────────────────────┤
│ チャット履歴                  │
├────────────────────────────┤
│ AI回答カード                  │
│ - 提案内容                    │
│ - 根拠                        │
│ - 参照データ                  │
│ - 信頼度                      │
│ - 注意点                      │
│ - 次の操作                    │
├────────────────────────────┤
│ 入力欄 / 送信ボタン            │
└────────────────────────────┘
```

### 8.3 相談カテゴリ

- 売上
- 集客
- 再来店
- 休眠復帰
- アップセル
- LINE
- SNS
- Google
- Lステップ要否
- レポート

### 8.4 AI回答カード項目

| 項目 | 内容 |
|---|---|
| 回答要約 | 短い結論 |
| 提案内容 | 実行すべき施策 |
| 対象 | 対象顧客または対象チャネル |
| 根拠 | 判断理由 |
| 参照データ | 売上、来店履歴、顧客状態など |
| 信頼度 | 高・中・低 |
| 注意点 | データ不足、表現リスク、過剰配信など |
| 次の操作 | 施策化、文案生成、対象者確認、レポート化 |

### 8.5 主な操作

| 操作 | 内容 |
|---|---|
| 施策にする | AI回答から施策を作成する |
| タスクにする | アクションプランに追加する |
| 文案を作る | 発信作成画面へ連携する |
| 対象者を見る | セグメント整理画面へ連携する |
| レポート化する | レポート画面へ連携する |
| 採用/保留/却下 | AI提案の評価を記録する |

## 25. S21 戦略目的整理画面

### 25.1 目的

施策提案の前段で、店舗が今月・今期に優先すべき売上改善目的と Why を確認する。目的、KPI候補、対象顧客、推奨チャネル、推奨施策候補を一画面で整理し、人間が施策化の可否を判断できる状態にする。

### 25.2 画面構成

```text
┌────────────────────────────┐
│ 期間 / 店舗 / 目的ステータス       │
├────────────────────────────┤
│ 戦略目的カード（目的・Why・信頼度） │
├──────────────┬─────────────┤
│ KPI候補         │ 対象顧客候補   │
├──────────────┬─────────────┤
│ 推奨チャネル     │ 推奨施策候補   │
├────────────────────────────┤
│ 根拠 / 注意点 / 不足データ         │
└────────────────────────────┘
```

### 25.3 表示項目

| 領域 | 表示内容 |
|---|---|
| 戦略目的 | 今月・今期の重点目的、期間、ステータス |
| Why/根拠 | 売上、来店、顧客状態、施策履歴に基づく判断理由 |
| KPI候補 | 売上、来店数、再来店率、客単価、休眠復帰数など |
| 対象顧客候補 | 新規、初回来店後、リピーター、休眠予備軍、休眠、VIP候補など |
| 推奨チャネル | LINE、個別連絡、SNS、Google投稿、店頭対応など |
| 推奨施策候補 | アクションプランや施策管理へ展開する候補 |
| AI品質情報 | 信頼度、注意点、不足データ |

### 25.4 Phase1範囲

Phase1では独立した高度な目標管理画面までは実装せず、S03ダッシュボードに「今月の重点目的カード」を追加するだけに留める。詳細なKPI目標管理、施策連携、月次レポート反映はPhase2以降とする。顧客向け発信に展開する場合は、既存の承認管理方針に従い必ず人間承認を通す。
