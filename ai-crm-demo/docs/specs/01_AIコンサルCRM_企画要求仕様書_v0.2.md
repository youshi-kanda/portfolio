## 1. プロジェクト概要

### 1.1 仮称

AIコンサルCRM

### 1.2 コンセプト

個人店・小規模店舗向けに、公式LINEを主要チャネルとして活用しながら、顧客データ・来店/売上データ・LINE友だちデータを統合し、AIが施策提案・配信文生成・対象者抽出・承認・LINE配信実行・結果分析まで支援する、AI搭載型LINE CRM。

### 1.3 一文説明

公式LINEを主要チャネルとする小規模店舗向けに、顧客整理・施策提案・AI文案生成・承認・LINE配信実行・結果分析・改善レポートをLステップより軽く一貫して提供するAI搭載型LINE CRM。

### 1.4 中心価値

本サービスの中心価値は、以下にある。

> 小規模店舗が、公式LINEで売上改善するために必要な「顧客整理・施策提案・配信文生成・LINE配信実行・結果分析・改善レポート」を、Lステップより軽く、配信実行まで一貫して使える形で提供すること。

### 1.5 解決したい課題

個人店・小規模店舗では、公式LINE、Instagram、Googleビジネスプロフィール、予約システム、顧客リストなどのツールは存在していても、それらをどう使えば売上改善につながるのかが分かりにくい。

特に以下の課題がある。

- 公式LINEで何を送ればよいか分からない
- 顧客をどう分類すればよいか分からない
- 公式LINEのタグ設計やセグメント配信が面倒
- Lステップなどの高度なMAツールは設定・運用が重い
- Lステップを導入するほどではないが、LINEをもっと活用したい
- InstagramやGoogleビジネスプロフィールで何を発信すればよいか分からない
- 顧客データはあるが、売上改善に活用できていない
- 新規集客・再来店・休眠復帰・アップセルの打ち手が属人的
- コンサルに依頼すると高額で継続しづらい
- 自社エリアで何が求められているか分からない
- 施策を実行しても、結果を振り返って改善できていない
- 代理店・コンサル側も、店舗診断、提案書作成、月次レポート作成に時間がかかる

### 1.6 提供価値

本システムは、店舗オーナー・店長・代理店/コンサルに対して以下の価値を提供する。

- 自社の現状が見える
- 顧客の状態・ニーズ・離脱理由が見える
- 自社エリアで求められているニーズが見える
- 今週・今月やるべきアクションが分かる
- 公式LINE配信文、Instagram投稿文、Google投稿文を作れる
- 顧客フォロー対象者を抽出できる
- 公式LINE側で複雑なタグ設計をしなくても、配信対象や施策意図を整理できる
- Lステップを使うべきか、公式LINEだけで足りるか判断できる
- 実行した施策の結果を振り返り、次の改善案を出せる
- 店舗専属のAIマーケティング担当者のように相談できる
- 代理店/コンサルが複数店舗の診断・提案・改善支援を効率化できる

## 2. 解決したい社会課題

### 2.1 社会課題の定義

本システムが解決しようとする社会課題は、地域の小規模事業者が、顧客データ・地域需要・デジタル発信を十分に活用できず、経験や勘に依存した集客・経営判断から抜け出しにくいことにある。

多くの地域店舗は、技術力・接客力・専門性を持っていても、以下のような構造的な課題を抱えている。

- 顧客データが予約台帳、公式LINE、SNS、紙、Excelなどに分散している
- 顧客の本当のニーズや離脱理由を把握できていない
- 何を発信すれば集客につながるか分からない
- 地域内でどのニーズが高まっているか把握できない
- コンサルティングやマーケティング支援を継続的に受ける予算がない
- 公式LINE、Instagram、Googleビジネスプロフィールなどの運用が属人的になっている
- 値引きやクーポン配信に頼り、長期的な顧客関係を作りにくい
- 経営改善のためのデータ活用が大企業や一部の強い事業者に偏っている

本システムは、こうした小規模店舗・地域事業者に対して、AIを活用した「相談できるマーケティング担当者」「実行できる経営改善パートナー」を提供することで、地域ビジネスのデータ活用格差を縮小することを目指す。

### 2.2 社会的に実現したい状態

本システムが目指す社会的な状態は以下である。

- 小規模店舗でも、データに基づいて集客・再来店・顧客フォローを改善できる
- 地域の顧客ニーズを把握し、必要なサービスを適切に届けられる
- 店舗が無理な広告費や過度な値引きに依存せず、既存顧客との関係性を深められる
- 店舗オーナーが孤独に経営判断を抱え込まず、AIに相談しながら改善を進められる
- 顧客側も、自分の悩みや状況に合った情報・サービスを受け取りやすくなる
- 地域ごとの需要データが蓄積され、新しいサービス開発や地域課題の把握に活かされる
- 小規模店舗を支援する代理店・コンサルが、属人的ではなく再現性ある支援を提供できる

### 2.3 解決する対象課題の定義

| 課題 | 内容 | 本システムの解決方針 |
|---|---|---|
| 意思決定の課題 | 何をすれば売上改善につながるか分からない | 自社状況・顧客状態・地域ニーズを分析し、次アクションを提案する |
| 実行の課題 | 配信文、投稿、顧客フォロー、施策管理が続かない | LINE/SNS/Google投稿文やアクションプランを生成し、実行管理する |
| 学習の課題 | 施策結果を振り返らず、改善サイクルが回らない | 実施結果を記録し、次回改善案・月次改善案を提示する |
| 運用負荷の課題 | Lステップや高度MAのタグ・シナリオ設計が重い | 本サービス側で顧客状態・施策意図を整理し、外部ツール側のタグを最小化する |
| 支援者の課題 | 代理店・コンサルが診断・提案・レポート作成に時間を取られる | 店舗診断・改善提案・月次レポートをテンプレート化・半自動化する |

## 3. プロダクトの位置づけ

### 3.1 既存ツールとの違い

| 種類 | 代表例 | 主な役割 | 弱点 |
|---|---|---|---|
| 予約システム | RESERVA、STORES予約、Airリザーブ、リザービア | 予約管理 | 集客改善・顧客育成までは弱い |
| LINE配信/MA | Lステップ、L Message、KUZEN、Mico Engage | LINE配信・シナリオ・タグ管理 | 戦略設計や運用設計が必要 |
| CRM | 各種顧客管理ツール | 顧客情報管理 | 何をすべきかまでは教えてくれない |
| SNS支援 | 投稿作成ツール、分析ツール | 発信補助 | 顧客データや売上とつながりにくい |
| コンサル | 人による支援 | 課題整理・改善提案 | 高額・属人的・継続しづらい |
| 本システム | AIコンサルCRM | 相談・分析・提案・発信・顧客管理・改善 | 初期データ設計と業種テンプレートが重要 |

### 3.2 狙うポジション

本システムは、予約システムや公式LINEを置き換えるものではなく、顧客理解から施策設計・LINE配信実行・結果分析までを一貫して担うAI搭載型LINE CRMとして位置づける。

位置づけは以下。

- 予約システム：予約を管理する
- 公式LINE：顧客との接点・配信チャネル
- Lステップ / L Message：高度な自動シナリオが必要な場合の任意ツール
- Instagram：新規・潜在層への発信
- Googleビジネスプロフィール：地域検索・口コミ・来店前接点
- 本システム：顧客理解→施策設計→AI文案生成→承認→**LINE配信実行**→結果分析→改善提案

### 3.3 公式LINE・Lステップとの関係性

本サービスでは、公式LINEを小規模店舗における主要な顧客接点として扱う。

一方で、Lステップは必須前提とはせず、高度なLINE配信・シナリオ運用が必要な場合に利用する任意ツールとして位置づける。

| ツール/領域 | 役割 |
|---|---|
| 公式LINE | 顧客との接点、配信口、問い合わせ、予約導線 |
| Lステップ / L Message | 高度なセグメント配信、ステップ配信、シナリオ実行 |
| 本サービス | 顧客整理、課題発見、施策設計、配信対象整理、発信文生成、改善提案 |
| Instagram | 新規・潜在層への発信、認知獲得 |
| Googleビジネスプロフィール | 地域検索、口コミ、来店前接点 |
| 予約システム / POS | 予約、来店、売上データの取得元 |

### 3.4 正しい位置づけ

本サービスは、顧客理解から施策設計・LINE配信実行・結果分析・改善提案までを一貫して担う。Lステップは高度なシナリオが必要な場合の任意ツールとして位置づける。

```text
予約/POS/顧客/発信/地域データ
        ↓
本サービス：顧客理解・施策設計・AI文案生成・承認
        ↓
本サービス：LINE配信実行（Broadcast / Multicast / ステップ配信）
        ↓
予約・来店・売上
        ↓
本サービス：配信結果取得・改善提案・月次レポート
```

※高度な自動シナリオ分岐が必要な場合はLステップを任意に併用する。

### 3.5 中心メッセージ

売上を上げるために、今やるべき行動が分かる。

より具体的には、

> 公式LINEは使っている。でも、何を送ればいいか分からない店舗向けに、顧客データから今やるべき集客・再来店・休眠復帰施策を提案するAIコンサルCRM。

## 4. Lステップ機能との対応方針

### 4.1 基本方針

本サービスはLステップの全機能を置き換えるものではない。

小規模店舗が本当に必要とするLステップ的な機能だけを、より軽く、分かりやすく、公式LINEだけでも運用できる形で提供する。

### 4.2 小規模店舗に必要なLステップ的機能

| 必要機能 | Lステップでの役割 | 本サービスでの対応方針 |
|---|---|---|
| 顧客分類 | タグ・友だち情報 | 顧客状態・推定ニーズ・次アクションとして本サービス側で整理 |
| セグメント配信 | タグ別配信 | 対象者リスト、配信目的、配信文を出力 |
| ステップ配信 | シナリオ配信 | 初回後、休眠、再来店などのアクションフローを提案 |
| リマインド | 予約前後の通知 | 予約データをもとにリマインド文と対象者を提案 |
| アンケート | 回答フォーム | 顧客ニーズ収集フォームとして設計 |
| 分析 | 配信・反応分析 | 施策結果、予約転換、売上影響を改善レポート化 |
| シナリオ設計 | 自動分岐 | AIが施策フローと分岐案を提案 |

### 4.3 Lステップに任せる機能（任意併用）

以下はLステップの得意領域として任意に併用する。本サービスが強制的に置き換えるものではない。

| 機能 | 理由 |
|---|---|
| 複雑な自動シナリオ分岐（10ステップ超） | 設計・保守が複雑で、Lステップの得意領域 |
| 個人別リッチメニュー出し分け | Lステップ側の仕様が充実している |
| 決済・販売 | 既存LINE拡張ツールが強い |
| 本格予約管理 | 予約システムの方が強い |
| 大規模MA | Mico、KUZENなどの領域 |

### 4.4 タグ設計方針

本サービスは「タグ不要」を目指すのではなく、「複雑なタグ設計を最小化する」ことを目指す。

#### 本サービス側で詳細管理する情報

- 顧客状態
- 推定ニーズ
- 行動阻害要因
- LTV
- 最終来店日
- 来店回数
- メニュー履歴
- 反応履歴
- 次アクション
- AI提案理由

#### 公式LINE / Lステップ側に渡す情報

- 配信対象者リスト
- タグ候補
- 配信目的
- 配信文
- 実施タイミング
- 注意点

#### 外部ツール側のタグ設計方針

公式LINEやLステップ側では、配信・シナリオ実行に必要な最小限のタグだけを使う。

例：

- 初回後フォロー対象
- 休眠復帰対象
- アップセル候補
- 回数券更新候補
- VIP
- 要個別対応
- 配信停止

詳細な判断理由や顧客ニーズは本サービス側で保持する。

## 5. 対象ユーザー

### 5.1 初期対象業種

初期は以下の3業種を優先対象とする。

1. エステ・美容サロン
2. 整体・接骨院・鍼灸院
3. パーソナルジム

### 5.2 初期対象から外す業種

以下は将来的な拡張対象とし、初期仕様では優先度を下げる。

- 美容室
- ネイル・まつ毛サロン
- 飲食店
- 学習塾・スクール
- 不動産
- 士業
- BtoBサービス

### 5.3 主な利用者

| 利用者 | 主な目的 |
|---|---|
| 店舗オーナー | 売上改善、集客改善、経営判断、月次改善 |
| 店長 | 日々の施策実行、スタッフ指示、顧客フォロー管理 |
| スタッフ | 担当顧客の確認、接客メモ登録、個別フォロー |
| 代理店/コンサル | 店舗診断、改善提案、月次レポート、運用支援 |
| Lステップ構築者 | タグ設計前の顧客整理、シナリオ設計、改善提案 |
| システム管理者 | テナント管理、権限管理、運用保守 |

### 5.4 想定ユーザー像

#### ペルソナA：小規模エステサロンのオーナー

- 1〜3名体制
- 公式LINEとInstagramを使っている
- 予約はホットペッパー、DM、LINE、電話などが混在
- 顧客管理は紙、Excel、予約システムに分散
- Lステップを導入するほどではないが、LINEを活用したい
- 何を発信すればよいか毎回悩んでいる
- 休眠客や再来店対策が弱い

#### ペルソナB：整体・接骨院の院長

- 新規集客はできるが、継続率に課題がある
- 回数券や継続プランの提案が属人的
- LINE配信はしているが、効果測定できていない
- 症状別フォローやセルフケア発信を強化したい

#### ペルソナC：パーソナルジムのオーナー

- 体験予約から入会への転換率を上げたい
- 既存会員の継続率を上げたい
- 食事管理や上位プランへのアップセルを強化したい
- 休眠・退会予備軍を早めに検知したい

#### ペルソナD：LINE運用代行者・Lステップ構築者

- 店舗ごとの現状診断に時間がかかる
- 顧客データをもとにしたタグ設計・シナリオ設計を効率化したい
- 提案書や月次レポートを標準化したい
- Lステップ導入が必要な店舗と、公式LINEだけで足りる店舗を見極めたい

## 6. 主要ユースケース

### 6.1 AIに相談する

ユーザーは、経営・集客・発信・顧客フォローに関する悩みをAIに相談できる。

相談例：

- 今月売上が落ちている理由を知りたい
- 今週何を発信すればよいか知りたい
- 休眠客を戻す施策を考えたい
- 新規集客を増やすには何から始めればよいか
- このエリアで刺さるメニューを考えたい
- LINE配信文を作ってほしい
- Instagram投稿を1週間分作りたい
- 初回来店後のフォローを改善したい
- Lステップが必要か判断したい
- 代理店向けの店舗診断レポートを作りたい

### 6.2 自社状況を見る

ユーザーは、売上、顧客、集客、発信、施策実行状況をダッシュボードで確認できる。

表示例：

- 売上傾向
- 新規顧客数
- リピート顧客数
- 客単価
- 来店周期
- 休眠顧客数
- メニュー別売上
- 発信頻度
- LINE/SNS反応
- 今週の改善優先度

### 6.3 顧客ニーズを見る

ユーザーは、顧客ごとの状態、推定ニーズ、行動阻害要因、次アクションを確認できる。

例：

- 初回来店後フォロー対象
- 継続迷い層
- 価格不安層
- 高意欲未予約層
- 休眠予備軍
- 休眠復帰候補
- 回数券更新候補
- アップセル候補
- VIP候補

### 6.4 エリア需要を見る

ユーザーは、自社エリアでどのようなニーズが高まっているかを確認できる。

初期は手入力・簡易調査・AI整理を中心とし、将来的に外部データ連携を検討する。

対象データ例：

- 商圏エリア
- 競合店舗
- 競合メニュー
- 競合価格帯
- Google検索傾向
- Googleビジネスプロフィールの検索語句
- 口コミ内容
- SNS投稿傾向
- 季節要因
- 地域イベント

### 6.5 今週のアクションプランを見る

ユーザーは、AIが提案する今週・今月のアクションを確認し、実行管理できる。

例：

- 月曜：休眠顧客へLINE配信
- 火曜：Instagram投稿「季節悩み」
- 水曜：初回来店後フォロー10名
- 木曜：高単価メニュー事例投稿
- 金曜：週末予約枠の告知

各アクションには以下を持たせる。

- 施策名
- 目的
- 対象
- 推奨タイミング
- 優先度
- 期待効果
- 必要作業時間
- 配信文・投稿文
- 実行手順
- 実行ステータス

### 6.6 発信文を作成する

ユーザーは、AIにより各媒体向けの発信文を生成できる。

対応媒体：

- 公式LINE
- Instagram
- Googleビジネスプロフィール
- メール
- SMS
- 店頭POP
- チラシ

### 6.7 施策結果を振り返る

- 次回改善案

代理店・コンサルは、店舗の顧客データ、売上データ、発信状況をもとに、改善提案を作成できる。

出力例：

- 店舗診断レポート

- 顧客状態レポート

## 7. 利用パターン

### 7.1 パターンA：公式LINEのみの小規模店舗

```text
顧客/予約/売上データ
↓
本サービスで顧客状態・課題・施策を整理
↓
公式LINE用の配信文・対象者・実行タイミングを出力
↓
公式LINEで手動/半自動配信
↓
結果を本サービスに戻す
↓
次回改善
```

このパターンを初期の本命とする。

### 7.2 パターンB：Lステップ/L Messageあり店舗

```text
顧客/予約/売上データ
↓
本サービスで施策設計・タグ案・配信文・改善案を作成
↓
Lステップ/L Messageで配信・シナリオ実行
↓
結果を本サービスに戻す
↓
月次改善レポート
```

このパターンでは、本サービスはLステップの設計・改善支援ツールとして機能する。

### 7.3 パターンC：代理店・コンサル利用

```text
店舗診断
↓
顧客データ/発信状況/売上課題を整理
↓
公式LINEだけで足りるか、Lステップが必要か判断
↓
改善提案書・月次レポート作成
↓
伴走支援
```

このパターンは初期営業として有力である。

## 10. AI出力ルール

AIの提案には必ず以下を含める。

| 項目 | 内容 |
|---|---|
| 提案内容 | 何をするか |
| 対象 | 誰に向けた施策か |
| 根拠 | なぜそう判断したか |
| 優先度 | 高・中・低 |
| 期待効果 | 何が改善するか |
| 注意点 | 法規制、過剰配信、値引き乱発など |
| 実行手順 | 何から始めるか |
| 発信用文面 | すぐ使える文案 |
| 推奨チャネル | 公式LINE、Instagram、Google、個別連絡など |
| 外部ツール連携要否 | 公式LINEのみでよいか、Lステップ等が必要か |

### 10.1 禁止・注意すべき出力

以下の表現は業種テンプレートごとに制御する。

- 効果を断定する表現
- 医療的効果を保証する表現
- 痩身・美容領域で誤認を招く表現
- 過度な煽り表現
- 個人情報を不必要に含む表現
- 本人同意のない再利用を前提にした表現
- 配信停止者への再配信を促す表現
- Lステップや外部ツールの導入を不要に断定する表現
- 売上改善を保証する表現

## 14. コアデータ活用方針

本システムでは、店舗の利用を通じて蓄積されるデータを、単なる顧客管理情報としてではなく、今後のプロダクト改善、新規サービス開発、業種別テンプレート高度化、地域需要分析に活用する。

ただし、個人情報・店舗情報・機密情報を扱うため、データ活用は透明性、同意、匿名化、目的限定を前提とする。

### 14.1 蓄積されるコアデータ

| データ種別 | 内容 | 将来的な活用可能性 |
|---|---|---|
| 顧客行動データ | 来店頻度、最終来店日、予約、キャンセル、再来店 | 休眠予測、再来店予測、業種別改善モデル |
| 顧客ニーズデータ | 悩み、目的、問い合わせ、アンケート、スタッフメモ | ニーズ分類、施策提案精度向上、業種別テンプレート化 |
| 施策データ | LINE配信、SNS投稿、キャンペーン、個別フォロー | 成功施策パターンの抽出、配信・発信テンプレート改善 |
| 反応データ | クリック、予約転換、来店、売上、返信 | 施策効果予測、次アクション推薦精度向上 |
| 売上・LTVデータ | 客単価、累計売上、メニュー別売上、回数券 | LTV改善モデル、アップセル提案、価格帯分析 |
| エリアデータ | 商圏、競合、地域ニーズ、季節需要 | 地域別需要マップ、業種別エリア戦略、出店・販促支援 |
| AI相談データ | 相談内容、提案内容、採用/不採用、結果 | AIコンサル精度向上、課題分類、ナレッジ蓄積 |
| 代理店支援データ | 診断内容、提案内容、採用施策、月次改善履歴 | 支援モデル高度化、代理店向けテンプレート改善 |

### 14.2 データ活用に関する原則

1. 目的明示
   データを何のために取得し、どの範囲で活用するかを明示する。

2. 同意管理
   顧客データ、店舗データ、AI学習・分析利用について、必要に応じて同意状態を管理する。

3. 匿名化・集計化
   個人や特定店舗が識別される形で、第三者提供や横断分析に使わない。

4. 店舗の利益保護
   ある店舗の営業ノウハウや顧客情報が、競合店舗に直接流用されないようにする。

5. AI出力の透明性
   AIの提案には、判断根拠、利用データ、注意点を可能な限り明示する。

6. 人間承認
   顧客への配信、重要な施策、外部発信は、原則として人間の確認・承認を挟む。

7. 法令・規約遵守
   個人情報保護法、各プラットフォーム規約、業種別広告規制に配慮する。
