# AIコンサルCRM 業種別広告表現チェック仕様書 v0.1

## 1. 本書の目的

本書は、AIコンサルCRMにおける広告表現チェック機能の仕様を定義するものである。

本サービスでは、公式LINE、Instagram、Googleビジネスプロフィール、メール、店頭POP、チラシ、代理店提案書などの文案をAIが生成・改善提案する。

そのため、エステ・美容サロン、整体・接骨院・鍼灸院、パーソナルジムなど、広告表現上のリスクが高い業種において、以下を制御する必要がある。

- 効果を断定する表現
- 医療的効果を想起させる表現
- 痩身・美容効果を保証する表現
- 景品表示法上、優良誤認・有利誤認につながる可能性のある表現
- ステルスマーケティング規制に関わるPR表記漏れ
- 口コミ・体験談・ビフォーアフターの不適切利用
- 期間限定・残りわずか等の虚偽または根拠不明な訴求
- 過度な不安訴求
- 外部発信前の人間承認漏れ

本書では、AI生成文・ユーザー入力文・施策文案に対して、どのようにリスク検出、修正提案、承認制御、ログ保存を行うかを定義する。

## 2. 基本方針

### 2.1 広告表現チェックの位置づけ

広告表現チェック機能は、法令適合性を保証するものではない。

本機能は、広告表現上のリスクを検出し、より安全な表現に修正するための支援機能である。

最終判断は、店舗運営者、代理店・コンサル、必要に応じて専門家が行う。

### 2.2 基本思想

| 方針 | 内容 |
|---|---|
| 保証しない | 本機能は法的適合性を保証しない |
| 事前警告する | 顧客向け・外部向け文案のリスクを配信前に警告する |
| 修正案を出す | 単にNGを出すのではなく、代替表現を提示する |
| 業種別に判定する | エステ、整体、ジムで注意すべき表現を分ける |
| 人間承認を必須にする | 顧客向けLINE文、SNS投稿、Google投稿は承認必須 |
| 根拠と注意点を表示する | なぜリスクがあるかを説明する |
| ログを残す | チェック結果、修正、承認履歴を保存する |

### 2.3 初期実装方針

初期では、完全な法令判定ではなく、以下を実装範囲とする。

- リスクキーワード検出
- 業種別注意表現辞書
- AIによる文脈チェック
- リスクレベル表示
- 修正案生成
- 人間承認フロー
- チェック結果ログ保存

## 3. チェック対象

### 3.1 対象文書・文案

| 対象 | チェック要否 | 理由 |
|---|---|---|
| 公式LINE配信文 | 必須 | 顧客へ直接届くため |
| 個別LINE文 | 必須 | 顧客へ直接届くため |
| Instagram投稿文 | 必須 | 外部公開されるため |
| Instagramリール台本 | 必須 | 外部公開されるため |
| Googleビジネスプロフィール投稿文 | 必須 | 外部公開されるため |
| 口コミ返信案 | 推奨 | 公開情報として残るため |
| メール配信文 | 必須 | 顧客へ直接届くため |
| SMS文 | 必須 | 顧客へ直接届くため |
| 店頭POP文 | 推奨 | 来店客に表示されるため |
| チラシ文 | 必須 | 不特定多数に配布されるため |
| 代理店提案書 | 推奨 | 店舗提案・営業資料として使われるため |
| 内部メモ | 原則不要 | 外部発信ではないため |
| AI相談回答 | 注意表示のみ | 内部利用だが誤認防止が必要なため |

### 3.2 チェックタイミング

| タイミング | 内容 |
|---|---|
| AI文案生成直後 | 生成文を自動チェックする |
| ユーザー編集後 | 編集後の文案を再チェックする |
| 承認依頼前 | 承認前にリスク状態を確定する |
| 承認時 | リスクあり文案の承認時に注意表示する |
| コピー/出力時 | 未承認または高リスク文案の利用を警告する |

## 4. リスクレベル定義

### 4.1 リスクレベル

| レベル | 定義 | システム挙動 |
|---|---|---|
| none | 明確なリスク表現なし | 通常表示 |
| low | 軽微な注意表現あり | 注意表示、修正案提示 |
| medium | 誤認・断定につながる可能性あり | 承認必須、修正推奨 |
| high | 法令・規約上の重大リスクが疑われる | 配信・出力を制限し、修正必須 |
| review_required | 専門家確認が望ましい | 承認時に専門家確認推奨を表示 |

### 4.2 リスク判定の観点

| 観点 | 内容 |
|---|---|
| 断定性 | 必ず、絶対、確実、永久などの表現 |
| 医療性 | 治る、完治、診断、治療、医学的効果など |
| 美容・痩身保証 | 痩せる、消える、即効、小顔になるなどの保証的表現 |
| 優良誤認 | 実際より著しく優れているように見せる表現 |
| 有利誤認 | 価格・キャンペーン条件を誤認させる表現 |
| No.1表現 | 根拠のない地域No.1、業界最高など |
| 口コミ・体験談 | 個人の結果を一般化する表現 |
| ビフォーアフター | 条件・個人差説明の不足 |
| ステマ | 広告・PRであることが分かりにくい投稿 |
| 不安訴求 | 過度に恐怖や不安を煽る表現 |
| 個人情報 | 顧客個人を特定できる情報の露出 |

## 5. 共通チェックルール

### 5.1 効果断定表現

| リスク表現例 | リスク | 修正方向 |
|---|---|---|
| 必ず改善します | 効果保証に見える | 改善を目指してサポートします |
| 絶対に変わります | 断定が強い | 変化を感じる方もいます |
| 確実に効果が出ます | 効果保証に見える | 状態に合わせて提案します |
| 永久に続きます | 継続効果の保証 | 継続的なケアがおすすめです |
| 即効で変わります | 過度な即効性訴求 | 変化の感じ方には個人差があります |

### 5.2 医療的表現

| リスク表現例 | リスク | 修正方向 |
|---|---|---|
| 治ります | 治療効果の断定 | ケアをサポートします |
| 完治します | 医療的保証 | 状態に合わせて整えます |
| 診断します | 医療行為の想起 | 状態を確認します |
| 治療できます | 医療行為の想起 | ケア・サポートを行います |
| 病気が改善します | 疾病改善の訴求 | 気になる場合は医療機関にご相談ください |

### 5.3 美容・痩身表現

| リスク表現例 | リスク | 修正方向 |
|---|---|---|
| 必ず痩せる | 痩身保証 | 目標に合わせてサポートします |
| シミが消える | 効果断定 | 肌を整えるケアを行います |
| たるみが治る | 医療・効果断定 | ハリ感を目指すケアです |
| 小顔になります | 結果保証 | すっきり感を目指します |
| セルライトが消える | 効果断定 | 気になる部位のケアをサポートします |

### 5.4 優良誤認・No.1表現

| リスク表現例 | リスク | 修正方向 |
|---|---|---|
| 地域No.1 | 根拠が必要 | 根拠がある場合のみ出典・期間を明記 |
| 業界最高 | 根拠が必要 | 当店が大切にしている強みとして表現 |
| 圧倒的効果 | 誇大表現 | 一人ひとりに合わせたケア |
| 他店より必ず良い | 比較根拠が必要 | 当店の特徴として説明 |
| 口コミ評価No.1 | 調査条件が必要 | 口コミで評価いただいている点として紹介 |

### 5.5 有利誤認・価格表示

| リスク表現例 | リスク | 修正方向 |
|---|---|---|
| 今だけ無料 | 条件不明確 | 対象条件・期間・範囲を明記 |
| 通常価格から大幅割引 | 通常価格の実態確認が必要 | 比較対象価格と期間を明記 |
| 本日限り | 実態がない場合は虚偽表示 | 実際の期間に合わせて表示 |
| 残りわずか | 在庫・枠数根拠が必要 | 残数が事実の場合のみ記載 |
| 先着限定 | 条件不明確 | 人数・期間・対象条件を明記 |

### 5.6 口コミ・体験談

| リスク | 注意点 |
|---|---|
| 個人の結果を一般化する | すべての人に同じ結果が出るように見せない |
| 加工された印象を与える | 画像加工・条件差を明示する |
| 顧客情報が特定される | 氏名、顔、身体情報、来店履歴に注意する |
| PR投稿であることが分かりにくい | 必要に応じてPR表記を入れる |
| 効果保証につながる | 個人の感想であることを明示する |

### 5.7 ステルスマーケティング・PR表記

| 対象 | 注意点 |
|---|---|
| インフルエンサー投稿 | 広告・PR・提供であることを明示する必要がある場合がある |
| モニター投稿 | モニター条件や提供関係を明示する |
| 口コミ依頼 | 見返りの有無や投稿条件に注意する |
| 代理店作成投稿 | 店舗の広告であることが分かる形にする |
| AI生成投稿 | 誤認を招く表現や架空口コミを避ける |

## 6. 業種別チェックルール

## 6.1 エステ・美容サロン

### 6.1.1 主なリスク

| リスク | 内容 |
|---|---|
| 痩身効果の断定 | 必ず痩せる、何kg痩せるなど |
| 肌悩み改善の断定 | シミが消える、たるみが治るなど |
| 医療行為との誤認 | 医療レベル、治療、診断など |
| ビフォーアフター | 条件・個人差説明不足 |
| 勧誘不安を煽る表現 | 不安やコンプレックスを過度に刺激する表現 |
| 化粧品・物販表現 | 薬機法上の効能効果表現に注意 |

### 6.1.2 NG表現・修正例

| NG表現 | 修正例 |
|---|---|
| 必ず痩せます | 目標に合わせたボディケアをサポートします |
| 1ヶ月で-5kg保証 | 生活習慣や目標に合わせたケアをご提案します |
| シミが消えます | 透明感のある印象を目指すケアです |
| たるみが治ります | ハリ感を目指したケアです |
| 毛穴がなくなります | 毛穴まわりをすっきり整えるケアです |
| 医療レベルの施術 | 専門的な視点で一人ひとりに合わせてケアします |
| 永久に効果が続きます | 継続的なケアで良い状態を保ちやすくします |

### 6.1.3 推奨表現

- 目指す
- サポートする
- 整える
- ケアする
- すっきり感
- ハリ感
- 透明感のある印象
- 状態に合わせた提案
- 変化の感じ方には個人差があります

### 6.1.4 注意文例

```text
※変化の感じ方には個人差があります。
※お肌やお身体の状態に合わせてご提案します。
※医療行為ではありません。
```

## 6.2 整体・接骨院・鍼灸院

### 6.2.1 主なリスク

| リスク | 内容 |
|---|---|
| 疾病治癒の断定 | 治る、完治、根本治療など |
| 医療広告との誤認 | 診断、治療、医学的に証明など |
| 保険適用の誤認 | 必ず保険が使えるなど |
| 症例表現 | 症状改善を保証するような表現 |
| 国家資格・施術範囲 | 表現範囲を誤るリスク |
| 不安訴求 | 放置すると危険、悪化するなどの過度な表現 |

### 6.2.2 NG表現・修正例

| NG表現 | 修正例 |
|---|---|
| 腰痛が治ります | 腰まわりの不調に合わせてケアします |
| 肩こりを完治 | 肩まわりの負担を軽くするサポートを行います |
| 根本治療します | 原因を一緒に確認し、状態に合わせてケアします |
| 医学的に改善 | 状態に合わせた施術を行います |
| 必ず保険が使えます | 保険適用には条件があります |
| 放置すると危険です | 気になる状態が続く場合は早めの相談がおすすめです |
| 病院より効果があります | 当院では日常生活のケアも含めてサポートします |

### 6.2.3 推奨表現

- 状態に合わせてケア
- 不調に合わせたサポート
- 身体の使い方を見直す
- 日常生活の負担を軽くする
- メンテナンス
- 早めの相談がおすすめ
- 必要に応じて医療機関への相談もご検討ください

### 6.2.4 注意文例

```text
※状態により感じ方には個人差があります。
※症状が強い場合や長引く場合は、医療機関への相談もご検討ください。
※保険適用には条件があります。
```

## 7. チェックロジック仕様

### 7.1 処理フロー

```text
文案入力またはAI生成
↓
媒体・業種・目的を取得
↓
ルールベースで危険語句を検出
↓
AIで文脈リスクを判定
↓
リスクレベルを算出
↓
該当箇所・理由・修正案を表示
↓
ユーザーが修正または承認依頼
↓
承認者が確認
↓
承認済み文案のみ外部利用可能
```

### 7.2 ルールベース判定

初期は、以下の辞書を持つ。

| 辞書 | 内容 |
|---|---|
| 共通NGワード辞書 | 必ず、絶対、確実、永久、No.1など |
| 医療系NGワード辞書 | 治る、完治、治療、診断、医学的など |
| 美容・痩身NGワード辞書 | 痩せる、消える、小顔、即効など |
| 価格・限定表現辞書 | 今だけ、本日限り、残りわずか、無料など |
| 不安訴求辞書 | 放置すると危険、手遅れ、悪化など |
| 業種別NGワード辞書 | エステ、整体、ジムごとのリスク表現 |

### 7.3 AI文脈判定

ルールベースだけでは判定しにくい以下をAIで補完する。

- 文脈上、効果保証に見えるか
- 不安を過度に煽っていないか
- 口コミや体験談が一般化されていないか
- 価格条件が不明確ではないか
- 医療行為や治療効果に見えないか
- 顧客個人情報が含まれていないか
- PR表記が必要そうな投稿ではないか

### 7.4 リスクスコア初期案

| 判定要素 | 加点例 |
|---|---|
| 効果断定ワードあり | +30 |
| 医療系ワードあり | +40 |
| 痩身保証ワードあり | +40 |
| No.1表現あり | +25 |
| 価格条件不明確 | +20 |
| 不安訴求あり | +20 |
| 口コミ・体験談の一般化 | +25 |
| 個人情報含有 | +50 |
| AI文脈判定で高リスク | +40 |

### 7.5 スコアとリスクレベル

| スコア | リスクレベル | 挙動 |
|---|---|---|
| 0〜19 | none | 通常表示 |
| 20〜39 | low | 注意表示 |
| 40〜69 | medium | 修正推奨、承認必須 |
| 70〜99 | high | 修正必須、出力制限 |
| 100以上 | review_required | 専門家確認推奨、出力制限 |

## 9. データベース反映

### 9.1 campaign_contents への保存

文案ごとに以下を保存する。

| カラム | 内容 |
|---|---|
| expression_risk_level | none / low / medium / high / review_required |
| expression_check_result | 検出箇所、理由、修正案、スコア |
| approval_status | draft / approval_pending / approved / rejected |

### 9.2 approvals への保存

承認管理では以下を保存する。

| カラム | 内容 |
|---|---|
| approval_target_type | content / campaign / report など |
| approval_target_id | 対象文案・施策ID |
| requested_by | 申請者 |
| approver_id | 承認者 |
| status | pending / approved / rejected |
| comment | コメント |
| requested_at | 申請日時 |
| decided_at | 承認・差戻し日時 |

### 9.3 audit_logs への保存

以下の操作は監査ログに残す。

- 文案生成
- 表現チェック実行
- 修正案適用
- 高リスク文案の承認依頼
- 承認
- 差戻し
- コピー/出力
- 外部投稿・配信済み登録

## 10. AIプロンプト要件

### 10.1 表現チェックAIの入力

| 入力 | 内容 |
|---|---|
| 文案本文 | チェック対象の文章 |
| 業種 | エステ、整体、ジムなど |
| 媒体 | LINE、Instagram、Google、メールなど |
| 施策目的 | 再来店、休眠復帰、アップセル、新規集客など |
| 対象顧客 | 新規、初回後、休眠、VIPなど |
| 店舗メニュー | 訴求対象のメニュー |
| キャンペーン条件 | 割引、期間、対象条件など |
| 禁止表現辞書 | 業種別・共通の注意表現 |

### 10.2 表現チェックAIの出力

AIは以下のJSON形式で出力する。

```json
{
  "risk_level": "medium",
  "risk_score": 55,
  "issues": [
    {
      "text": "必ず痩せます",
      "category": "effect_guarantee",
      "reason": "痩身効果を保証する表現に見えるため",
      "severity": "high",
      "suggestion": "目標に合わせた身体づくりをサポートします"
    }
  ],
  "overall_comment": "効果保証に見える表現が含まれるため、修正後に承認してください。",
  "requires_human_approval": true,
  "requires_expert_review": false
}
```

### 10.3 発信文生成AIへの制約

発信文生成AIは、最初から以下を避ける。

- 必ず、絶対、確実、永久などの断定表現
- 治る、完治、治療、診断などの医療的表現
- 痩せる、消える、即効などの保証表現
- 根拠のないNo.1表現
- 架空の口コミ
- 実態のないキャンペーン表現
- 過度な不安訴求
- 顧客個人情報の露出

## 11. 外部発信・承認制御

### 11.1 承認必須条件

以下は承認必須とする。

| 条件 | 内容 |
|---|---|
| 顧客向け配信 | 公式LINE、メール、SMSなど |
| 外部公開投稿 | Instagram、Googleビジネスプロフィールなど |
| campaign_contents.approval_status != approved | 未承認文案 |
| expression_risk_level が low 以上 | リスク表現がある文案 |
| キャンペーン価格表示あり | 割引・無料・限定など |
| 口コミ・体験談利用あり | 顧客の声を使う場合 |
| ビフォーアフター利用あり | 結果表現を含む場合 |

### 11.2 出力制限

| 状態 | システム挙動 |
|---|---|
| 未承認 | 外部利用前に承認を要求 |
| medium以上 | 修正推奨を強く表示 |
| high以上 | コピー/出力を制限可能にする |
| review_required | 専門家確認推奨を表示し、管理者承認を要求 |

## 12. MVP実装範囲

### 12.1 MVPで必須

| 機能 | 理由 |
|---|---|
| 共通NGワード辞書 | 最低限の危険表現を検出するため |
| 業種別NGワード辞書 | エステ・整体・ジムでリスクが異なるため |
| AI文脈チェック | 辞書だけでは文脈判断できないため |
| リスクレベル表示 | ユーザーが危険度を理解するため |
| 修正案生成 | 実務で使える表現に直すため |
| 承認ステータス | 外部発信前の人間確認に必須 |
| チェック結果保存 | 後から確認できるようにするため |

### 12.2 MVPで後回しでもよい

| 機能 | 理由 |
|---|---|
| 専門家レビューワークフロー | 初期は注意表示と管理者承認で代替可能 |
| 画像内テキストチェック | OCRや画像判定が必要で実装負荷が高い |
| ビフォーアフター画像判定 | 法令・画像解析ともに難易度が高い |
| SNS投稿の自動PR判定 | 投稿文脈や契約関係が必要 |
| 法令アップデート自動反映 | 初期は手動更新でよい |
| 外部投稿APIとの連動停止 | 初期はAPI連携しないため不要 |
