# AIコンサルCRM エステサロン向け初期テンプレート詳細仕様書 v0.1

## 1. 本書の目的

本書は、AIコンサルCRMにおける初期対象業種である「エステ・美容サロン」向けの業種テンプレート詳細仕様を定義するものである。

AIコンサルCRMでは、すべての業種を汎用的に扱うのではなく、業種ごとの商習慣、顧客心理、来店周期、売上構造、広告表現リスクを踏まえたテンプレートを持つことで、AI診断・顧客インサイト・施策提案・発信文生成・広告表現チェックの品質を安定させる。

本書では、エステサロン向けに以下を定義する。

- 業種特性
- 主要KPI
- 顧客状態判定ルール
- 顧客ニーズ分類
- 行動阻害要因
- セグメント定義
- 推奨施策テンプレート
- 公式LINE文案テンプレート
- Instagram投稿テーマ
- Googleビジネスプロフィール投稿テーマ
- 広告表現チェックルール
- AI診断・提案時の判断基準

## 2. 対象業種定義

### 2.1 対象範囲

本テンプレートの対象は、主に以下のようなエステ・美容サロンである。

| 区分 | 内容 |
|---|---|
| フェイシャルエステ | 肌質改善、毛穴、乾燥、くすみ、ハリ感ケアなど |
| 痩身エステ | ボディライン、むくみ、引き締め、体型悩みなど |
| 脱毛サロン | ムダ毛ケア、自己処理負担軽減など |
| リラクゼーション系エステ | 癒し、リフレッシュ、疲労感ケアなど |
| ブライダルエステ | 挙式前の集中ケア、見た目の印象づくりなど |
| 小規模美容サロン | 個人経営、少人数運営、地域密着型サロン |

### 2.2 初期MVPで優先するサブ業種

初期MVPでは、以下を優先する。

1. フェイシャルエステ
2. 痩身・ボディケア系エステ
3. 脱毛サロン

ただし、最初から過度に細分化すると実装・運用が重くなるため、MVPでは `esthetic` を共通業種として扱い、サブ業種は店舗設定で補足する。

## 3. エステサロンの業種特性

### 3.1 商習慣

| 項目 | 特性 |
|---|---|
| 初回体験 | 初回体験メニューから継続につなげるケースが多い |
| 継続利用 | 単発利用より、複数回・定期来店で売上が安定しやすい |
| 回数券・コース | 回数券、月額、集中コースなどが売上構造に影響する |
| 顧客心理 | 効果実感、価格不安、継続理由、スタッフとの信頼関係が重要 |
| 発信媒体 | Instagram、公式LINE、Googleビジネスプロフィールとの相性が高い |
| 予約導線 | LINE、予約サイト、電話、DMなど複数導線になりやすい |
| 口コミ | 口コミ・紹介・ビフォーアフター訴求の影響が大きいが表現リスクもある |

### 3.2 主な経営課題

| 課題 | 内容 |
|---|---|
| 初回後離脱 | 初回体験後、2回目予約につながらない |
| 休眠化 | 一定期間来店がなく、そのまま離脱する |
| 客単価低下 | 低単価メニューやクーポン依存になる |
| 回数券更新不足 | コース終了後の継続提案が弱い |
| 新規集客依存 | 既存顧客の再来店・紹介が弱い |
| 発信継続不足 | LINEやSNSで何を発信すべきか分からず止まる |
| 価格不安 | 継続コースや回数券の価格に不安を持たれる |
| 効果訴求リスク | 表現を強めすぎると広告規制上のリスクがある |

### 3.3 顧客心理

エステサロンの顧客は、単に「安いから行く」のではなく、以下の心理で予約・継続を判断する。

| 心理 | 内容 |
|---|---|
| 悩みを理解してほしい | 肌・体型・年齢・生活習慣など個別の悩みを理解されたい |
| 変化を感じたい | 何らかの実感や納得感がないと継続しづらい |
| 強く売り込まれたくない | 高額コースへの強引な勧誘を警戒しやすい |
| 価格に納得したい | 継続費用に見合う理由が必要 |
| 自分に合うか確認したい | サロン・スタッフ・施術との相性を重視する |
| 忘れやすい | 行きたい気持ちはあっても、日常の中で後回しになりやすい |
| 季節で悩みが変わる | 乾燥、紫外線、むくみ、冷え、露出時期などで関心が変わる |

## 4. 主要KPIテンプレート

### 4.1 必須KPI

| KPI | 定義 | 利用目的 | 初期優先度 |
|---|---|---|---|
| 新規予約数 | 期間内の新規予約数 | 集客力確認 | 高 |
| 初回来店数 | 初回予約から実際に来店した人数 | 来店率確認 | 高 |
| 初回後2回目予約率 | 初回来店後、2回目予約につながった割合 | 初回後離脱改善 | 最重要 |
| リピート率 | 一定期間内に再来店した顧客割合 | 継続力確認 | 高 |
| 休眠顧客数 | 一定期間来店がない顧客数 | 休眠復帰施策 | 高 |
| 客単価 | 売上 ÷ 来店数 | 単価改善 | 高 |
| LTV | 顧客ごとの累計売上 | 優良顧客分析 | 高 |
| 回数券・コース契約率 | 初回または再来店後に契約した割合 | 継続売上確認 | 中 |
| 回数券更新率 | 回数券終了前後で更新した割合 | 継続改善 | 中 |
| 施策予約転換率 | 配信・投稿後に予約へつながった割合 | 施策効果確認 | 高 |

### 4.2 補助KPI

| KPI | 定義 | 利用目的 |
|---|---|---|
| LINE返信率 | LINE配信に対する返信割合 | 顧客関係性確認 |
| LINEクリック率 | 配信リンクのクリック割合 | 訴求内容確認 |
| Instagram投稿頻度 | 一定期間内の投稿回数 | 認知活動確認 |
| Google投稿頻度 | GBP投稿回数 | 地域検索対策 |
| 口コミ数 | 期間内の口コミ件数 | 信頼形成確認 |
| キャンセル率 | 予約に対するキャンセル割合 | 予約導線・期待値確認 |
| 次回予約取得率 | 来店時に次回予約を取れた割合 | 店頭オペレーション改善 |

### 4.3 警戒指標

| 指標 | 注意すべき状態 | 推奨対応 |
|---|---|---|
| 初回後2回目予約率が低い | 初回体験が継続につながっていない | 初回後フォロー・次回来店理由の明確化 |
| 休眠顧客が増えている | 再来店導線が弱い | 休眠復帰LINE・季節訴求 |
| 客単価が下がっている | 低単価メニュー依存 | 上位メニュー提案・価値訴求 |
| 回数券更新が少ない | 継続提案タイミングを逃している | 残回数別フォロー |
| LINE反応が低い | 配信内容が合っていない | セグメント・文案改善 |
| 口コミが少ない | 来店前の信頼材料が不足 | 満足顧客への口コミ依頼 |
| 結果未入力が多い | 改善サイクルが止まる | 施策結果入力リマインド |

## 5. 顧客状態判定テンプレート

### 5.1 顧客状態一覧

| 顧客状態 | 定義 | 主な目的 |
|---|---|---|
| 新規リード | LINE友だち追加、問い合わせ、DM等はあるが未予約 | 初回予約化 |
| 初回予約済 | 初回予約済みで未来店 | 来店率向上・不安解消 |
| 初回来店後 | 初回来店済みで次回予約なし | 2回目予約促進 |
| 2回目来店前 | 2回目予約済みで未来店 | 継続動機づけ |
| リピーター | 2回以上来店 | 継続・単価向上 |
| 回数券利用中 | 回数券・コースを利用中 | 消化率・更新率向上 |
| 回数券更新候補 | 残回数が少ない、または終了間近 | 更新提案 |
| 休眠予備軍 | 標準来店周期を超え始めている | 離脱防止 |
| 休眠顧客 | 一定期間来店がない | 復帰促進 |
| VIP候補 | 来店頻度・累計売上・紹介可能性が高い | 優先対応・紹介促進 |
| 離脱リスク高 | キャンセル、反応低下、不満メモ等がある | 個別フォロー |

### 5.2 初期判定ルール

MVPでは、厳密な機械学習ではなく、ルールベース + AI補助で判定する。

| 顧客状態 | 初期判定条件案 |
|---|---|
| 新規リード | 顧客登録あり、来店履歴なし、問い合わせまたはLINE友だち追加あり |
| 初回予約済 | 予約あり、来店履歴なし、予約日が未来 |
| 初回来店後 | 来店回数 = 1、次回予約なし、最終来店日から30日以内 |
| 2回目来店前 | 来店回数 = 1、次回予約あり |
| リピーター | 来店回数 >= 2、最終来店日から標準来店周期内 |
| 回数券利用中 | 契約または回数券残数あり |
| 回数券更新候補 | 回数券残数 <= 2、または契約終了予定日が近い |
| 休眠予備軍 | 最終来店日から45〜89日経過、次回予約なし |
| 休眠顧客 | 最終来店日から90日以上経過、次回予約なし |
| VIP候補 | 来店回数 >= 6、または累計売上が店舗上位20% |
| 離脱リスク高 | キャンセル複数回、配信反応低下、不満メモ、来店周期超過 |

### 5.3 来店周期の初期値

| サブ業種 | 標準来店周期 | 休眠予備軍 | 休眠 |
|---|---:|---:|---:|
| フェイシャル | 30日 | 45日以上 | 90日以上 |
| 痩身・ボディ | 14〜30日 | 45日以上 | 90日以上 |
| 脱毛 | 30〜60日 | 75日以上 | 120日以上 |
| リラクゼーション | 30〜45日 | 60日以上 | 120日以上 |
| ブライダル | イベント日基準 | 要個別判定 | 要個別判定 |

### 5.4 判定時の注意

- 来店周期は店舗設定で変更可能にする
- 回数券・コース利用中の顧客は、単純な来店間隔だけで休眠判定しない
- ブライダル系は挙式日・目的日を考慮する
- 配信停止者にはLINE施策を提案しない
- 不満・クレームメモがある顧客は一斉配信より個別対応を優先する

## 7. 行動阻害要因テンプレート

| 阻害要因 | 内容 | 推奨対応 |
|---|---|---|
| 忘れている | 来店タイミングを忘れている | 軽いリマインド、季節の悩み訴求 |
| 予約理由が弱い | 今行く理由が明確でない | 悩み別・季節別の来店理由を提示 |
| 価格不安 | 継続費用への不安がある | 価値訴求、相談導線、無理な売り込み回避 |
| 効果実感不足 | 変化を感じにくい | 施術後の変化確認、目標再設定 |
| 忙しい | 予約が後回しになる | 空き枠提示、短時間メニュー案内 |
| 他店比較中 | 他店や医療系と比較している | 強み、口コミ、通いやすさを提示 |
| 勧誘不安 | 高額コースを売り込まれそうで不安 | 相談だけでも可、無理な勧誘をしない姿勢 |
| 気まずさ | 久しぶりで連絡しづらい | 気軽に再開できる文面 |
| 不満・不安 | 前回対応に不満がある可能性 | 一斉配信より個別ヒアリング |

## 8. セグメントテンプレート

```text
{{顧客名}}様
```

```text
こんにちは、{{店舗名}}です。

前回のケアから少し期間が空いている方は、状態確認も兼ねて一度メンテナンスしておくと安心です。

```

### 10.3 休眠復帰文案

```text
こんにちは、{{店舗名}}です。

お久しぶりの方にもご来店いただきやすいよう、現在の状態に合わせたケア相談を受け付けています。

前回から期間が空いていても問題ありません。
今のお悩みやご予定に合わせて、無理のないメニューをご提案します。

気になることがあれば、このLINEにそのままご返信ください。
```

### 10.4 回数券更新候補向け文案

```text
{{顧客名}}様
いつもご来店ありがとうございます。

現在のケアも残り{{残回数}}回となりましたので、次回ご来店時にこれまでの状態を一緒に確認しながら、今後の通い方を相談できればと思います。
```

```text
もちろんご無理のない範囲で大丈夫です。
```

## 13. 広告表現チェックテンプレート

### 13.1 高リスク表現

| リスク表現 | 理由 | 修正例 |
|---|---|---|
| 必ず痩せます | 痩身効果の保証 | 目標に合わせてサポートします |
| シミが消えます | 効果断定 | 肌を整えるケアを行います |
| たるみが治ります | 医療的・効果断定 | ハリ感を目指すケアです |
| 小顔になります | 結果保証 | すっきり感を目指します |
| 永久に効果が続きます | 継続効果保証 | 継続的なケアがおすすめです |
| 地域No.1 | 根拠が必要 | 根拠がある場合のみ出典・期間を明記 |
| 絶対変わる | 断定が強い | 変化の感じ方には個人差があります |
| 医学的に改善 | 医療的効果の想起 | 状態に合わせたケアを行います |

### 13.2 注意表現

| 注意表現 | 注意点 | 修正方向 |
|---|---|---|
| 即効 | 過度な即効性訴求に見える | 施術後にすっきり感を感じる方もいます |
| 劇的変化 | 誇大表現に見える | 変化を目指してサポートします |
| 若返り | 医療・美容効果の断定に見える | 年齢に応じた印象ケア |
| 老け顔改善 | 不安訴求が強い | 年齢による印象変化が気になる方へ |
| セルライト除去 | 効果断定に見える | 気になる部位のケア |

### 13.3 安全な表現方針

| 方針 | 例 |
|---|---|
| 断定しない | 〜を目指します、〜をサポートします |
| 個人差に配慮する | 感じ方には個人差があります |
| 医療行為に見せない | ケア、サポート、整える、確認する |
| 不安を煽りすぎない | 気になる方へ、早めのケアがおすすめです |
| 相談導線にする | まずはお気軽にご相談ください |


### 15.2 月次コメント例

```text
今月は新規予約数は維持できていますが、初回来店後の2回目予約率に改善余地があります。
特に、初回来店後に次回予約がない顧客へのフォローが不足しているため、来店後3〜5日以内の状態確認LINEを優先施策とします。

一方で、リピーターの来店頻度は安定しているため、回数券更新候補への個別フォローを行うことで、継続売上の安定化が期待できます。
```

### 15.3 代理店向け提案コメント例

```text
現状の課題は、新規集客そのものよりも、初回来店後の継続導線にあります。
そのため、まずは大規模な広告施策ではなく、既存の公式LINEを活用した初回後フォローと休眠予備軍への再来店促進を優先することを推奨します。

店舗側の運用負荷を抑えるため、月2回のLINE配信と週1回のInstagram投稿から始め、施策結果を記録しながら改善していく方針が現実的です。
```
