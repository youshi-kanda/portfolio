# AIコンサルCRM 業種別テンプレート仕様書 v0.1

## 1. 本書の目的

本書は、AIコンサルCRMにおける業種別テンプレートの仕様を定義するものである。

本サービスは、個人店・小規模店舗が公式LINEを主要な顧客接点として活用しながら、顧客状態・売上課題・地域ニーズを整理し、集客・再来店・顧客フォロー・発信施策をAIに相談しながら実行できるAIコンサル型CRMである。

業種別テンプレートは、AI提案の品質を安定させるための中核マスタである。

本書では、以下を明確にする。

- 初期対象業種をどう定義するか
- 業種ごとの主要KPIをどう設定するか
- 業種ごとの顧客状態をどう判定するか
- 業種ごとの顧客ニーズ・阻害要因をどう分類するか
- 業種ごとの推奨施策をどうテンプレート化するか
- 業種ごとの公式LINE、Instagram、Google投稿テーマをどう設計するか
- 業種ごとの広告表現・注意表現をどう扱うか
- AI相談・顧客インサイト・施策提案・発信作成にどう反映するか

---

## 2. 業種別テンプレートの基本方針

### 2.1 目的

業種別テンプレートの目的は、AIが一般論だけで提案するのではなく、業種特有の商習慣、顧客心理、来店周期、売上構造、表現リスクを踏まえた提案を行えるようにすることである。

### 2.2 基本思想

本サービスでは、すべての業種を最初から汎用的に扱うのではなく、初期対象業種を絞り、業種ごとのテンプレートを深く作る。

初期対象業種は以下とする。

1. エステ・美容サロン
2. 整体・接骨院・鍼灸院
3. パーソナルジム

### 2.3 テンプレートの役割

| 役割 | 内容 |
|---|---|
| AI診断の前提 | 業種ごとの売上・顧客・再来店課題を判断する |
| 顧客状態判定 | 業種ごとの来店周期や継続パターンに応じて状態判定する |
| セグメント提案 | 休眠、初回後、継続迷い、アップセル候補などを抽出する |
| 施策提案 | 業種別に効果が出やすい施策を候補化する |
| 発信作成 | LINE、Instagram、Google投稿のテーマ・文面を生成する |
| 表現チェック | 業種ごとの禁止・注意表現を検出する |
| レポート | 業種に合ったKPI・改善提案を出す |

### 2.4 初期は固定マスタでもよい

初期MVPでは、業種別テンプレートを管理画面から編集可能にする必要はない。

初期は、コードまたは設定ファイル、DB固定マスタとして管理し、運用データが蓄積された段階で管理画面化を検討する。

## 3. テンプレート構成

### 3.1 テンプレートカテゴリ

業種別テンプレートは、以下のカテゴリで構成する。

| テンプレート種別 | 内容 |
|---|---|
| 業種基本情報 | 業種名、サブ業種、主な商材、主な顧客目的 |
| KPIテンプレート | 重要KPI、補助KPI、警戒指標 |
| 顧客状態テンプレート | 新規、初回後、リピーター、休眠などの判定基準 |
| ニーズ分類テンプレート | 顧客の悩み、目的、期待、阻害要因 |
| セグメントテンプレート | 施策対象者の抽出条件 |
| 施策テンプレート | 初回後、再来店、休眠復帰、アップセル施策 |
| 発信テーマテンプレート | LINE、Instagram、Google投稿テーマ |
| 文案テンプレート | 媒体別の基本文面構成 |
| 広告表現テンプレート | 禁止表現、注意表現、修正例 |
| レポートテンプレート | 月次レポート、診断レポートの着眼点 |

### 3.2 DB管理上の想定

DB設計では `industry_templates` に以下のように保存する。

| カラム | 内容 |
|---|---|
| industry | esthetic / bodycare / gym など |
| template_type | kpi / customer_state / need_category / campaign / content / prohibited_expression |
| name | テンプレート名 |
| config_json | テンプレート本体 |
| description | 説明 |
| status | active / inactive |

## 4. 共通KPIテンプレート

### 4.1 共通で見るKPI

3業種共通で以下を確認する。

| KPI | 内容 | 利用目的 |
|---|---|---|
| 新規予約数 | 新規顧客の予約数 | 集客力確認 |
| 初回来店数 | 初回予約から来店した人数 | 来店率確認 |
| 2回目予約率 | 初回来店後、2回目予約につながった割合 | 初回後フォロー改善 |
| リピート率 | 一定期間内の再来店割合 | 継続力確認 |
| 休眠顧客数 | 一定期間来店がない顧客数 | 休眠復帰施策 |
| 客単価 | 売上 ÷ 来店数 | 単価改善 |
| LTV | 顧客ごとの累計売上 | 優良顧客・アップセル分析 |
| 施策実行率 | 提案施策のうち実行した割合 | 運用定着確認 |
| 施策反応率 | 配信・投稿に対する返信/クリック等 | 発信改善 |
| 予約転換率 | 施策後に予約へつながった割合 | 施策効果確認 |

### 4.2 共通の警戒指標

| 指標 | 注意すべき状態 |
|---|---|
| 初回来店後の次回予約なし | 2回目来店につながらず離脱しやすい |
| 最終来店日から一定期間経過 | 休眠化の可能性が高い |
| 配信反応低下 | 発信内容や頻度が合っていない可能性 |
| キャンセル増加 | 予約導線、価格、期待値、都合の問題がある可能性 |
| 客単価低下 | 低単価メニュー偏重、アップセル不足の可能性 |
| 施策未実行 | 提案があっても行動に移せていない |
| 結果未入力 | 改善サイクルが回らない |

## 5. 共通顧客状態テンプレート

### 5.1 顧客状態一覧

| 顧客状態 | 基本定義 | 主な目的 |
|---|---|---|
| 新規リード | 問い合わせ・友だち追加・資料請求などがあるが未予約 | 初回予約化 |
| 初回予約済 | 初回予約済みで未来店 | 来店率向上 |
| 初回来店後 | 初回来店済みで次回予約なし | 2回目予約促進 |
| リピーター | 2回以上来店 | 継続・単価向上 |
| 休眠予備軍 | 通常来店周期を超え始めた顧客 | 離脱防止 |
| 休眠顧客 | 一定期間来店がない顧客 | 復帰促進 |
| VIP候補 | 来店頻度・累計売上・紹介可能性が高い顧客 | 優先対応・紹介促進 |
| 離脱リスク高 | キャンセル、反応低下、来店周期超過などがある顧客 | 個別フォロー |

### 5.2 判定時の注意

顧客状態は固定ではなく、以下の要素で再判定する。

- 最終来店日
- 来店回数
- 次回予約有無
- メニュー履歴
- 売上/LTV
- 配信反応
- キャンセル履歴
- 接客メモ
- 業種別の標準来店周期

## 6. 共通ニーズ・阻害要因テンプレート

### 6.1 ニーズ分類

| ニーズ分類 | 内容 | 例 |
|---|---|---|
| 効果確認 | 効果や変化を確認したい | 施術後の変化確認、トレーニング成果確認 |
| 価格不安 | 価格や継続費用が気になる | 回数券、月額、継続コースへの不安 |
| 継続迷い | 継続する理由が弱い | 2回目予約、継続プラン、更新迷い |
| 季節悩み | 季節により悩みが変わる | 乾燥、肩こり、体型変化、冷えなど |
| 決め手不足 | 興味はあるが予約・購入に至らない | 事例不足、FAQ不足、空き枠不明 |
| 再開きっかけ不足 | 行きたい気持ちはあるが後回し | 休眠顧客、忙しさ、優先度低下 |
| 高度化ニーズ | より良い結果・上位サービスを求める | 上位コース、個別プログラム、集中ケア |
| 関係性重視 | スタッフや店舗との関係性が重要 | 個別メッセージ、VIP対応、紹介依頼 |

### 6.2 行動阻害要因

| 阻害要因 | 内容 | 対応方針 |
|---|---|---|
| 忘れている | 来店タイミングを忘れている | 軽いリマインド、季節訴求 |
| 予約理由が弱い | 行く理由が明確でない | 悩み別の来店理由を提示 |
| 価格不安 | 費用対効果に不安がある | 価値訴求、ライトプラン、相談導線 |
| 効果実感不足 | 効果を感じにくい | 変化確認、目標再設定 |
| 面倒・忙しい | 予約や来店が後回し | 空き枠提示、短時間メニュー提案 |
| 他店比較中 | 他店と比較している | 強み、事例、口コミ訴求 |
| 不満・不安 | 前回体験に不満がある可能性 | 個別フォロー、ヒアリング |

## 7. エステ・美容サロン テンプレート

### 7.1 業種特性

| 項目 | 内容 |
|---|---|
| 主な目的 | 美容、肌悩み、痩身、リラクゼーション、自己投資 |
| 主な商材 | フェイシャル、痩身、脱毛、ボディケア、回数券、物販 |
| 顧客心理 | 効果実感、価格、継続理由、信頼感、恥ずかしさ、季節悩み |
| 継続要因 | 効果実感、スタッフ信頼、通いやすさ、肌/体の変化実感 |
| 離脱要因 | 効果不明、価格不安、予約の後回し、勧誘不安、他店比較 |

### 7.2 主要KPI

| KPI | 目的 |
|---|---|
| 初回体験予約数 | 新規集客確認 |
| 初回来店率 | 予約後の来店確認 |
| 2回目予約率 | 初回後フォロー確認 |
| 回数券購入率 | 継続化確認 |
| 回数券更新率 | LTV向上確認 |
| 休眠復帰数 | 既存顧客掘り起こし |
| 物販売上 | ホームケア提案確認 |
| 客単価 | メニュー構成・アップセル確認 |

### 7.3 顧客状態判定目安

| 状態 | 判定目安 |
|---|---|
| 初回来店後 | 初回来店済み、次回予約なし |
| 休眠予備軍 | 最終来店から45〜60日程度 |
| 休眠顧客 | 最終来店から60〜90日以上 |
| 回数券更新候補 | 回数券残数1〜2回、または契約終了間近 |
| アップセル候補 | リピートあり、上位メニュー未体験 |
| VIP候補 | 高頻度来店、高LTV、紹介可能性あり |

※ 実際の閾値は店舗メニューの標準来店周期により調整する。

### 7.4 ニーズ分類

| ニーズ | 具体例 |
|---|---|
| 肌悩み | 乾燥、毛穴、くすみ、ハリ、たるみなど |
| 痩身・ボディ | 体型、むくみ、冷え、引き締めなど |
| 癒し・リラクゼーション | 疲れ、ストレス、睡眠、リフレッシュ |
| 効果確認 | 前回施術後の変化確認 |
| 価格不安 | 回数券、継続コース、物販購入の不安 |
| 勧誘不安 | 強く売り込まれたくない心理 |
| 季節悩み | 乾燥、紫外線、冷え、イベント前ケア |

### 7.5 推奨施策テンプレート

| 施策 | 対象 | 内容 |
|---|---|---|
| 初回来店後フォロー | 初回来店後3〜7日 | 変化確認、次回目的提案、相談導線 |
| 休眠予備軍フォロー | 最終来店45〜60日 | 季節悩み・メンテナンス訴求 |
| 休眠復帰施策 | 最終来店60〜90日以上 | 軽い近況確認、再開きっかけ、空き枠案内 |
| 回数券更新提案 | 残数1〜2回 | これまでの変化整理、次の目的提案 |
| 物販提案 | 施術履歴と悩みが明確な顧客 | ホームケア提案、使い方説明 |
| イベント前訴求 | ブライダル、旅行、季節イベント前 | 目的別ケア提案 |

### 7.6 発信テーマ

#### 公式LINE

- 前回施術後の調子確認
- 季節の肌悩み対策
- 空き枠案内
- 回数券残数・更新案内
- ホームケアの使い方
- 休眠顧客への近況確認

#### Instagram

- ビフォーアフターではなく、悩み別ケア解説
- 施術の流れ
- スタッフ紹介
- 店舗の雰囲気
- お客様のよくある質問
- 季節の美容Tips

#### Googleビジネスプロフィール

- 今月のおすすめメニュー
- 季節悩みに合わせた投稿
- 予約枠案内
- 口コミへの返信
- 初めての方向け案内

### 7.7 注意表現

| 避ける表現 | 修正方向 |
|---|---|
| 必ず痩せる | 目標に合わせたサポート |
| シミが消える | 肌を整えるケア |
| たるみが治る | ハリ感を目指すケア |
| 永久に効果が続く | 継続的なケアをおすすめ |
| 即効で改善 | 変化の感じ方には個人差があります |
| 医療レベル | 専門的な視点でサポート |

## 8. 整体・接骨院・鍼灸院 テンプレート

### 8.1 業種特性

| 項目 | 内容 |
|---|---|
| 主な目的 | 身体の不調ケア、姿勢、疲労、痛み予防、メンテナンス |

| 継続要因 | 体感、説明納得感、セルフケア、通いやすさ |
| 離脱要因 | 改善実感不足、通院負担、価格、予約忘れ、症状が落ち着いた |

### 8.2 主要KPI

| KPI | 目的 |
|---|---|
| 初回予約数 | 新規集客確認 |
| 初回来院率 | 予約後来院確認 |
| 2回目予約率 | 初回後の継続化確認 |
| 継続来院率 | 通院計画の定着確認 |
| 回数券購入率 | 自費施術の継続確認 |
| 休眠復帰数 | メンテナンス再開確認 |
| キャンセル率 | 予約定着・期待値管理確認 |
| 自費比率 | 売上構造確認 |

### 8.3 顧客状態判定目安

| 状態 | 判定目安 |
|---|---|
| 初回来院後 | 初回来院済み、次回予約なし |
| 継続中 | 2回以上来院、次回予約あり |
| 休眠予備軍 | 標準来院周期を超過 |
| 休眠顧客 | 最終来院から45〜90日以上 |
| メンテナンス候補 | 症状が落ち着き、定期ケア対象 |
| 回数券更新候補 | 残数1〜2回 |
| 離脱リスク高 | キャンセル増加、次回予約なし、反応低下 |

### 8.4 ニーズ分類

| ニーズ | 具体例 |
|---|---|
| 痛み・不調 | 肩こり、腰痛、首、膝、疲労など |
| 姿勢・身体の使い方 | 猫背、巻き肩、骨盤、歩き方など |
| メンテナンス | 不調予防、定期ケア |
| セルフケア | ストレッチ、生活習慣、運動提案 |
| 価格・通院頻度不安 | 何回通う必要があるか、費用感 |
| 保険適用誤認 | 保険が使えると思っている |
| 効果実感 | 施術後の変化や再発防止 |

### 8.5 推奨施策テンプレート

| 施策 | 対象 | 内容 |
|---|---|---|
| 初回来院後フォロー | 初回来院後1〜3日 | 状態確認、次回の目的、セルフケア案内 |

| 休眠復帰施策 | 最終来院45〜90日以上 | 季節不調、身体チェック、軽い相談案内 |
| セルフケア配信 | 症状別セグメント | ストレッチ、姿勢注意、生活アドバイス |
| 回数券更新提案 | 残数1〜2回 | これまでの変化、今後のメンテナンス提案 |
| キャンセル後フォロー | キャンセル後未予約 | 予約再調整、無理のない案内 |

#### Googleビジネスプロフィール

- 施術内容紹介

### 8.7 注意表現

| 避ける表現 | 修正方向 |

| 必ず良くなる | 個人差があります |
| 病気が治る | 医療機関への相談も検討 |
| 保険が必ず使える | 条件により異なります |

## 9. パーソナルジム テンプレート

### 9.1 業種特性

| 項目 | 内容 |

| 離脱要因 | 忙しさ、成果実感不足、価格、モチベーション低下 |

### 9.2 主要KPI

| KPI | 目的 |
|---|---|
| 体験予約数 | 新規集客確認 |
| 体験来店率 | 体験予約から来店への転換確認 |
| 体験入会率 | 体験から契約への転換確認 |
| 継続率 | 月額・回数券継続確認 |
| 退会予備軍数 | 離脱防止 |
| 上位プラン移行率 | アップセル確認 |
| 食事指導申込率 | 追加価値提案確認 |
| 休眠復帰数 | 再開促進 |

### 9.3 顧客状態判定目安

| 状態 | 判定目安 |
|---|---|
| 体験予約済 | 体験予約あり、未来店 |
| 体験後未入会 | 体験済み、入会なし |
| 入会初期 | 入会後1ヶ月以内 |
| 継続中 | 継続プラン利用中 |
| 退会予備軍 | 来店頻度低下、予約なし、反応低下 |
| 休眠顧客 | 一定期間来店なし、契約終了後未再開 |
| アップセル候補 | 継続中、目標更新・成果停滞・上位ニーズあり |
| VIP候補 | 長期継続、高LTV、紹介可能性あり |

### 9.4 ニーズ分類

| ニーズ | 具体例 |
|---|---|
| ダイエット | 体重、体脂肪、見た目の変化 |
| 筋力向上 | 筋肉量、姿勢、体力 |
| 健康習慣 | 運動不足、生活改善 |
| 食事管理 | 食事指導、栄養、間食 |
| 継続不安 | 続けられるか不安 |
| 価格不安 | 月額・回数券・上位プランの費用 |
| モチベーション低下 | 成果停滞、忙しさ、飽き |
| 目標再設定 | 新しい目標、停滞期突破 |

### 9.5 推奨施策テンプレート

| 施策 | 対象 | 内容 |
|---|---|---|
| 体験前リマインド | 体験予約済 | 当日の流れ、不安解消、持ち物案内 |
| 体験後フォロー | 体験後未入会 | 目標整理、入会不安の解消、相談導線 |
| 入会初期フォロー | 入会後1ヶ月以内 | 習慣化支援、目標再確認、成果記録 |
| 来店頻度低下フォロー | 予約頻度低下 | 無理なく再開できる案内 |
| 退会予備軍フォロー | 予約なし・反応低下 | 目標再設定、プラン見直し相談 |
| 上位プラン提案 | 継続中・成果停滞 | 食事指導、集中プラン、個別サポート |
| 休眠復帰施策 | 退会・休眠顧客 | 再開キャンペーンではなく近況確認と再設計提案 |

## 13. 広告表現チェック共通仕様

### 13.1 共通禁止・注意表現

| 種別 | 例 | 対応 |
|---|---|---|
| 効果断定 | 必ず、絶対、確実に | 警告・修正提案 |
| 医療的表現 | 治る、完治、診断、治療効果 | 警告・修正提案 |
| 美容効果断定 | 消える、永久、即効 | 警告・修正提案 |

| 過度な不安訴求 | 放置すると危険 | 警告 |
| 虚偽の限定訴求 | 本日限り、残りわずか | 条件確認 |
| ステマリスク | PR表記なしの案件投稿 | PR表記確認 |

### 13.2 修正方針

| リスク表現 | 修正方向 |
|---|---|
| 断定する | 目指す、サポートする、整えるに変更 |
| 治療を想起させる | ケア、メンテナンス、相談に変更 |
| 過度な成果訴求 | 個人差、条件、継続性を補足 |
| 不安を煽る | 悩みに寄り添う表現へ変更 |
| 強い売り込み | 相談・確認・選択肢提示に変更 |

## 16. MVPで必須のテンプレート

MVPで最低限必要なテンプレートは以下である。

| テンプレート | 必須理由 |
|---|---|
| 業種別KPI | ダッシュボードとレポートの前提になる |
| 顧客状態テンプレート | 顧客インサイトAIの前提になる |
| ニーズ分類テンプレート | 顧客理解と文案生成の前提になる |
| 施策テンプレート | 今週のアクション提案に必要 |
| 公式LINE文案テンプレート | 初期価値に直結する |

### 16.1 MVPで後回しでもよいもの

| テンプレート | 理由 |
|---|---|
| Instagram詳細テンプレート | 初期は簡易投稿案でも価値が出る |
| Google投稿詳細テンプレート | 初期は汎用テンプレートでも対応可能 |
| 地域需要テンプレート | 外部データ連携前は手入力中心でよい |
| 管理画面での編集機能 | 初期は固定マスタでよい |
| 業種別ベンチマーク | データ蓄積後に実装すべき |
